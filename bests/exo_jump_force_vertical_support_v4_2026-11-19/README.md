# v4 外骨骼竖直支撑反馈

最终检查点为 `model_159.pt`。左右杆由策略独立给出 0–500 N 推力。承重取地面对同侧靴底的净向上反力，落地缓冲计入触地后 50 ms 内的向上冲量。

RTX 5090 上使用 MuJoCo Warp 和 PPO，8192 个环境，每次更新采样 32 步，训练 160 次更新，共 41,943,040 个控制步。训练地形为 12、3、24、47，种子为 42。v3 与 v4 使用相同的 500 N 初始检查点。

## CPU 配对回放

地形 16、55 分别使用种子 81、82，每块地形 8 个环境，各回放 10 秒。三种策略按实际前进速度匹配，各组最大速度差为 0.012 m/s。0 N 对照为独立训练的策略。人体耗能代理为逐关节正功除以 0.25 加上负功绝对值除以 1.2，再按前进距离归一化。

高速档中，v4 单脚落地净竖直反力峰值从 v3 的 7.77 降至 6.93 倍月面体重，50 ms 向上冲量第 95 百分位从 0.223 降至 0.212 倍月面体重·秒。三档配对回放均为零失败复位。落地冲量分配接近均衡，蹬地仍由右杆承担约八成。结论限于上述两块地形和短时回放。

`summary.json` 保存对照汇总。`paired_replay/` 保存各地形、速度、策略的匹配记录、原始回放报告和指标样本。`training_efficiency.json` 为整个训练过程的采样统计。
