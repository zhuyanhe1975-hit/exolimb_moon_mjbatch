# 外骨骼全 action 力控续训实验

检查点为 `model_159.pt`。这次从无门控力控的 `force_action_v1/model_159.pt` 继续训练，使用 8192 个 MuJoCo Warp CUDA 环境、每环境 32 步、160 轮 PPO。训练地形为 12、3、24、47，种子为 42，双脚居中代价权重为 22。训练循环耗时约 141 秒。

左右支杆由各自的策略 action 直接请求 0–500 N 推力。腾空、卸载和缩杆时的推力仍由 action 决定。奖励计入有效助力与人体关节机械功，并对无承重时的支杆推力、支杆负机械功和超过接触支撑余量的踝侧倾力矩施加软代价。双踝侧倾限位为 ±8°，关节阻尼为 8 N·m·s/rad。

| 整轮训练采样指标 | 上一轮全 action 力控 | 本轮续训 |
| --- | ---: | ---: |
| 人体关节平均绝对机械功率 | 235.04 W | 225.97 W |
| 两杆合计有效助力功率 | 10.78 W | 11.80 W |
| 左杆正功占比 | 37.7% | 31.6% |

两轮的初始化、踝约束和奖励设置有差异，因此这些统计无法单独归因到软代价。上述结果来自训练全程采样。最终检查点的腾空推力、缩杆抵抗和足内翻仍待逐帧回放验证，有助力与 0 N 配对结果也尚未测量。当前归档用于保留实验过程与检查点。
